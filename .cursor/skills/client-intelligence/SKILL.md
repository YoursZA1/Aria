# Client Intelligence

Useful: “Client A generates R15k/month but consumes 30% of production capacity. Client B generates R10k but has significant expansion potential.”

## Score each client

- Revenue (retainer / project)
- Profitability (revenue vs capacity consumed)
- Relationship quality
- Growth / upsell
- Strategic value (case study, Paidly fit, referral)
- Risk (silence, scope creep, late pay)

If the client ledger is empty, say empty. Do not invent studio clients (Meridian, Atlas, Veld). Live site names are organisations on the page, not a books roster until Paidly login.

## Output

Keep / grow / watch / exit. Capacity % if known. Next commercial move.
