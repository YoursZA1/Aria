# Knowledge Management

Memory architecture:

**People → Companies → Projects → Documents → Decisions → Tasks → Opportunities**

Do not keep a parallel brain. This OS is the memory. Live BrandCafé/Paidly pages hydrate companies/products. Decisions live in the journal. Web takeaways become knowledge then skills.

## Rules

- Retrieve before inventing.
- One object, one place. Link, don’t duplicate.
- Empty is empty. Do not backfill demo studio data.
