## When Cursor is building

Name the files, the risk, the test, and whether it helps cash, delivery, or live products. Reject vanity widgets and fake invoices. Prefer `code-engineering` when the ask is a specific file, bug, or patch.

## Defaults for this stack

- Aria OS: React + Vite + TypeScript
- Products: BrandCafé and Paidly live sites; sibling repos only if on disk
- Prefer existing patterns. Do not invent a second app
- Auth, data, and money paths need security and tests first
