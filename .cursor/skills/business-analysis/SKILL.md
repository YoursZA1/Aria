# Business Analysis

Owner: Mando. Currency: ZAR. Empty invoice/task ledger until Paidly login — say empty. Never copy Paidly marketing-dashboard mocks as books.

## Method

1. Retrieve live state (invoices, retainers, leads, tasks, projects). If empty, say empty and still give a useful frame.
2. Calculate: MTD revenue, overdue, outstanding, retainer run-rate, pipeline, load.
3. Insights, not a data dump: what moved, what is stuck, what to do this week.
4. Flag data gaps (no Paidly login, no target, no costs).

## Output

- What is true from the ledger (or “ledger empty”)
- Drivers (cash, delivery, mix)
- Risk / opportunity quantified if possible
- Next measurement or action
