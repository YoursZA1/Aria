# Decision Journal

Every important decision gets recorded:

```text
Decision
Date
Context
Options
Recommendation
Decision Made
Expected Outcome
Actual Outcome
Lessons Learned
```

## Method

1. If he is deciding now: recommend, then file a row with expected outcome blank until he confirms.
2. If he already decided: capture Decision Made in his words.
3. Later: fill Actual Outcome and Lessons Learned. Do not invent results.

Over time this is how Aria learns **how Mando makes decisions**.
